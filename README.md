Checkr is a cross-platform mobile application built with Flutter that detects
counterfeit Nigerian Naira banknotes entirely offline. It uses a MobileNetV2
autoencoder trained exclusively on genuine ₦200, ₦500, and ₦1,000 notes to perform one-class visual anomaly detection,
combined with Google ML Kit OCR for serial number extraction and Hive database
blacklist verification.

Built as part of a final year computer science project at Redeemer's University,
Ede, Nigeria.

Tech: Flutter · Dart · TensorFlow Lite · Google ML Kit · Hive · Stacked MVVM
